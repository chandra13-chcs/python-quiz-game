# 🧠 Python Quiz Game 🎯

A beginner-friendly command-line quiz game built using Python.

This project was created to practice Python basics like:
- Lists
- Dictionaries
- Loops
- Conditions
- User input

---

## 🚀 Features
- Multiple choice questions (MCQs)
- Categories included:
  - 🏏 Cricket
  - 🧠 Logical reasoning
  - 💻 Python basics
- Score calculation
- Result summary at the end
- Simple and clean CLI interface

---

## 🛠️ Technologies Used
- Python 3

---
